## Pelaporan Bug / Kendala

Jika menemukan error, mohon laporkan di sini agar kami dapat mengklasifikasikan keparahannya berdasarkan **Bug Severity Definition** di bawah:

### Klasifikasi Severity (Panduan Tim Teknis)
- **Critical**: Login gagal, Sistem lumpuh total, Kehilangan data. (Bloker rilis)
- **High**: Data/Akses bocor lintas-role (RBAC error). (Bloker rilis)
- **Medium**: Error fungsional tertentu (mis. tombol ekspor gagal) tetapi aplikasi masih bisa digunakan. (Idealnya fix sebelum rilis)
- **Low**: Kesalahan tampilan minor (typo, warna, alignment). (Fix pada *patch* berikutnya)
