# Panduan Pengelola BK & Admin (Admin Guide v1.0)

## Selamat Datang, Tim BK & Administrator!
Dokumen ini memuat panduan operasional harian untuk memproses pengaduan, menentukan disposisi, mengelola akun, dan mengekspor laporan.

---

## 🔑 1. Login ke Dashboard Operasional
1. Akses halaman `/login`.
2. Masukkan email resmi sekolah dan kata sandi Anda.
3. Setelah berhasil, Anda akan diarahkan ke **Dashboard Overview**.

---

## 📋 2. Memproses Tiket Pengaduan (Petugas BK)
1. Buka menu **Manajemen Tiket**.
2. Pilih tiket dengan indikator prioritas tinggi atau peringatan SLA Overdue.
3. Buka **Detail Tiket** untuk melihat ringkasan AI & tingkat risiko otomatis.
4. Gunakan tombol **Disposisi 1-Klik** untuk memperbarui status penanganan atau memberikan respon kepada pelapor.

---

## 👑 3. Kelola Pengguna & Peran (Administrator)
1. Akses menu **Manajemen Pengguna** di `/dashboard/users`.
2. Untuk menambah pengajar/BK baru, klik **+ Tambah Pengguna Baru**.
3. Gunakan filter pencarian untuk menemukan pengguna dan sesuaikan perannya (Admin, BK, Guru, Siswa).

---

## 📊 4. Unduh Laporan Resmi Sekolah
1. Buka menu **Pusat Laporan** di `/dashboard/reports`.
2. Tentukan rentang tanggal laporan.
3. Klik **Unduh Laporan (.csv)** untuk membuka file rekap di Excel.
